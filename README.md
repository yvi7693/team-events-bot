# Team Events Bot

Telegram-бот, который напоминает команде о созвонах и встречах в общем чате, отмечает участников и в момент начала даёт ссылку на звонок.

## Возможности

- **Все уведомления — в общем чате команды.** Напоминания, начало встречи, новые ивенты, переносы, изменения и отмены приходят только туда, с отметкой участников: `@all`, если ивент для всей команды (в Telegram нет настоящего @all, поэтому каждый участник отмечен невидимой ссылкой и получает уведомление), иначе — участники по именам. В личку бот сам ничего не присылает — там только ответы на твои действия.
- **Общий чат — только для напоминаний.** Команды и настройки там не работают, меню команд не показывается.
- **Напоминание — только главное:**

  ```
  ⏰ Демо заказчику · через 10 мин
  сегодня, 12:00–12:45

  Повестка
  Показ MVP, обсуждение сроков

  🔗 Подключиться к звонку
  📣 @all
  [⏰ Опоздаю] [🕑 Перенести]
  ```

  «Опоздаю» — повторное нажатие отменяет; кто опаздывает, видно строкой «⏰ Опоздает: …» в самой карточке. «Перенести» продолжает разговор в личке с ботом.
- **Ссылка на звонок** — если она указана у ивента, то в каждом напоминании строкой «🔗 Подключиться к звонку».
- **Начало встречи (🚀) — без кнопок.**
- **Изменять ивенты можно только в личке с ботом** (`/events` → карточка → «✏️ Изменить», или `/new`).
- **Два вида ивентов:**
  - 🔁 **Регулярные** (дейли, еженедельный созвон, ретро раз в 2 недели) — для всей команды;
  - • **Разовые** — для выбранных участников: в общем чате отмечаются только они.
- **Перенос в одно касание:** +15 мин, +30 мин, +1 ч, на завтра или своё время. У регулярных можно перенести «только этот раз» или «всю серию». В общий чат уходит уведомление «было → стало», напоминания пересчитываются, отметки «опоздаю» сохраняются.
- **Редактировать может любой участник:** название, длительность, ссылку, повестку, участников, дни повтора, напоминания. Удалить ивент или отменить одно вхождение может только организатор.
- **Календарь прямо в Telegram (Mini App):** кнопка «📅 Календарь» в меню бота открывает календарь на месяц. Под днём — точки по числу ивентов, а если их больше трёх — число. Можно переключать «Мои / Вся команда», открыть ивент с повесткой и ссылкой, отметить «опоздаю», а для переноса или правки — открыть карточку в личке с ботом.
- **`/week`** (в личке): твои ивенты на ближайшие 7 дней с листанием по неделям.
- **Часовые пояса:** у каждого свой. Время везде показывается в поясе читателя, а в карточке ещё и в поясах коллег. Регулярные ивенты держат локальное время организатора при переходе на летнее/зимнее время.
- **Конфликты:** при создании, переносе или смене участников бот предупреждает, у кого и с каким ивентом пересечение. Регулярные проверяются на 4 недели вперёд.
- **Создание двумя способами:** пошаговый диалог с кнопками или одной строкой.

## Напоминания по умолчанию

| Тип | Когда напоминать | Почему |
|---|---|---|
| Разовый | за 1 день, за 1 ч, за 10 мин | день — чтобы успеть перестроить планы; час и 10 минут — чтобы не забыть |
| Регулярный 3+ раз в неделю (дейли) | за 10 мин | он и так в привычке, частые напоминания раздражают |
| Регулярный реже (еженедельный) | за 1 ч, за 10 мин | раз в неделю легко забыть |
| Любой | в момент начала | с повесткой и ссылкой на звонок, без кнопок |

Набор настраивается для каждого ивента: 1 день, 3 ч, 1 ч, 30, 15, 10, 5 мин.

## Стек

- Python 3.13, [aiogram 3](https://docs.aiogram.dev/) — Telegram Bot API, long polling
- SQLite через aiosqlite
- `zoneinfo` — часовые пояса и переход на летнее время
- Docker / docker-compose — запуск на сервере
- pytest + pytest-asyncio — тесты

## Быстрый старт

### 1. Создай бота

1. Напиши [@BotFather](https://t.me/BotFather) команду `/newbot` и получи токен.
2. Privacy mode можно оставить включённым: в группе бот слушает только команды и кнопки, а все диалоги идут в личке.

### 2. Запусти

**Через Docker (для сервера):**

```bash
git clone <repo-url> team-events-bot && cd team-events-bot
cp .env.example .env        # впиши BOT_TOKEN
docker compose up -d --build
docker compose logs -f
```

**Локально:**

```bash
python3.13 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env        # впиши BOT_TOKEN
set -a; source .env; set +a
.venv/bin/python -m bot
```

### 3. Подключи команду

1. Каждый участник жмёт «Старт» у бота в личке, выбирает часовой пояс. Без этого бот не знает человека: не отметит его в напоминаниях и не покажет время в его поясе.
2. Кто-то из зарегистрированных добавляет бота в общий чат (можно админом — прав на управление чатом ему не нужно). Чат сразу становится командным, а бот присылает кнопку «Подключиться к боту» для тех, кто ещё не нажал «Старт». Если бота добавит человек, не нажимавший «Старт», чат не привяжется. Если бота удалить из чата — привязка снимется. Переход группы в супергруппу бот отслеживает сам.
3. В личке у бота: `/new`.

Основной часовой пояс общего чата задаётся переменной `TEAM_TZ`.

## Команды

| Команда | Где | Что делает |
|---|---|---|
| `/new` | личка | создать ивент пошагово |
| `/new Название \| когда \| …` | личка | создать одной строкой |
| `/week` | личка | твои ивенты на 7 дней |
| `/calendar` | личка | открыть календарь |
| `/events` | личка | список ивентов, по нажатию — карточка с кнопками |
| `/tz` | личка | часовой пояс (`/tz Asia/Almaty`, `/tz UTC+5`) |
| `/team` | личка | кто в команде, их пояса и текущее время |
| `/cancel` | личка | прервать текущий диалог |

### Создание одной строкой

Первые два поля — название и время. Остальные распознаются по виду и могут идти в любом порядке.

```
/new Дейли | 10:00 | 15м | по будням | https://meet.google.com/abc-defg-hij
/new Планирование | пн 11:00 | 1ч | еженедельно
/new Ретро | пт 16:00 | 1ч30м | каждые 2 недели | Что улучшить в процессе
/new Демо заказчику | 05.11 14:00 | 45м | @anna @oleg | https://zoom.us/j/1 | Показ MVP
/new Обед командой | завтра 13:00 | 1ч | все
```

- **Когда:** `15:30`, `завтра 10:00`, `послезавтра 9:00`, `пт 11:00`, `05.11 14:00`, `05.11.2027 14:00`. Для регулярных достаточно `10:00` — старт с ближайшего подходящего дня.
- **Длительность:** `15м`, `1ч`, `1ч30м`, `1.5ч`, `90 мин`
- **Повтор:** `по будням` / `дейли`, `ежедневно`, `еженедельно`, `каждый пн,ср`, `еженедельно: пн-ср`, `каждые 2 недели пт`
- **Участники:** `@ник @ник` или `все`. Без этого поля бот спросит кнопками.
- **Ссылка:** любой `https://…`
- **Повестка:** всё остальное

## Как это устроено

- **Время.** Все моменты хранятся в UTC. Регулярный ивент хранит локальные дату и время и пояс организатора и разворачивается во вхождения на лету. Поэтому дейли «в 10:00 по Москве» не съезжает у коллег в других странах при переходе на летнее время.
- **Вхождение** — конкретный раз проведения ивента. Его ключ — исходное время начала. Перенос «только этот раз» и отмена хранятся как override для этого ключа. По нему же хранятся отметки «опоздаю», поэтому они переживают перенос.
- **Планировщик** раз в 20 секунд ищет напоминания, время которых наступило, и записывает каждую отправку в журнал `sent`. Время начала входит в ключ записи, поэтому после переноса напоминания уходят заново, а после рестарта бота дублей нет. Напоминание, опоздавшее больше чем на 15 минут (например, бот был выключен), не шлётся.
- **Карточки.** Бот запоминает все отправленные карточки и при изменении времени или отметок перерисовывает их во всех чатах.
- **Диалоги** (создание, правка, ввод времени) идут только в личке. Если нажать «Перенести» или «Изменить» под карточкой в группе, бот продолжит в личке.

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `TEAM_TZ` | нет | основной пояс команды (по умолчанию `Europe/Moscow`) |
| `TEAM_CHAT_ID` | нет | ID общего чата; обычно не нужен — чат привязывается сам, когда бота добавляют в группу |
| `DB_PATH` | нет | путь к файлу SQLite (`data/bot.sqlite3`) |
| `LOG_LEVEL` | нет | `INFO` / `DEBUG` |
| `PUBLIC_URL` | для календаря | публичный HTTPS-адрес веб-сервера бота, например `https://cal.example.com` |
| `WEB_PORT` | нет | порт веб-сервера (`8080`) |
| `PUBLIC_URL_FILE` | нет | файл, из которого бот на лету перечитывает `PUBLIC_URL` (для временных туннелей) |

## Календарь: настройка HTTPS

Telegram открывает Mini App только по HTTPS. Бот слушает `WEB_PORT` (8080), а снаружи нужен HTTPS.

**На сервере с доменом** проще всего поставить [Caddy](https://caddyserver.com/): он сам получает сертификат. Caddyfile:

```
cal.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

После этого впиши в `.env` `PUBLIC_URL=https://cal.example.com` и перезапусти бота. Кнопка «📅 Календарь» появится в меню у всех.

**Для проверки с ноутбука** подойдёт временный туннель Cloudflare, аккаунт не нужен:

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:8080
```

Скопируй выданный адрес `https://….trycloudflare.com` в `PUBLIC_URL` и перезапусти бота. Адрес меняется при каждом запуске туннеля, так что для постоянной работы нужен сервер.

Если сеть блокирует Cloudflare, подойдёт SSH-туннель localhost.run (ничего ставить не нужно). Бесплатный localhost.run меняет домен прямо во время работы, поэтому запускай его через скрипт: он переподключается при обрыве и пишет актуальный адрес в `data/public_url.txt`. Бот с `PUBLIC_URL_FILE=data/public_url.txt` раз в 15 секунд перечитывает этот файл и сам обновляет кнопку «📅 Календарь».

```bash
scripts/tunnel.sh
```

## Ограничения и что можно добавить

- Состояние незаконченных диалогов хранится в памяти: при рестарте недописанный `/new` придётся начать заново. Сами ивенты, ответы и журнал напоминаний лежат в SQLite и не теряются.
- Одна команда на один экземпляр бота (один общий чат).
- Идеи на будущее: статистика посещаемости, напоминание организатору о тех, кто не ответил.
